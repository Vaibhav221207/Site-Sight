# Build It Right! — Civil Engineering Material & Staging Simulator

> An interactive educational web application designed to visualize material selection, structural constraints, and sequential staging across four core civil infrastructure types.

## 🏗️ Overview

**Build It Right!** bridges civil engineering domain knowledge with interactive software. Instead of relying on static textbook tables, the tool models real-world material performance and staging logic—enforcing structural dependencies and providing instant technical feedback on engineering failures.

### Key Features
* **4 Infrastructure Modules:** Retaining Walls, Bridges, Dams, and Skyscrapers.
* **19 Sequential Staging Steps:** Enforces real-world construction ordering (foundations, substructure, superstructure, finishes).
* **70+ Material Choices:** Mapped directly to specific civil failure explanations (e.g., soil liquefaction under foundation load, improper tensile reinforcement).
* **Dynamic Visual Feedback:** Visual cross-sections update dynamically as valid structural decisions are made.
* **Zero-Dependency Architecture:** Built with pure Vanilla JavaScript, HTML5, and CSS3—requiring zero build tools or external frameworks.

---

## 🛠️ Technical Architecture & Workflow

* **Frontend:** Vanilla JavaScript (ES6 IIFE modular structure), HTML5, CSS3.
* **Civil Logic:** System architecture, material constraint mapping, and 4D staging dependencies authored to reflect civil engineering principles.
* **Workflow:** AI-assisted rapid prototyping utilized for frontend interface assembly and UI styling.
* **Hosting:** Lightweight static deployment on GitHub Pages.
